# Контент тренажёра

Сценарии и справочник поставляются как версионируемые данные, а не как код
(FR30–FR32). Добавление сценария не требует изменений в Go-файлах и релиза.

## Состав

| Файл | Назначение |
|---|---|
| `risk_signals.json` | Каталог признаков риска. Общий словарь контента (M5), оценки (M3) и интерфейса (M6) |
| `scenarios/scenario.schema.json` | Схема файла сценария. Контракт между контентом и движком, зафиксирован в день 1 |
| `scenarios/*.json` | Сценарии тренировки |

## Как добавить сценарий

1. Создайте `scenarios/<code>.json` по схеме `scenario.schema.json`.
   В VS Code схема подхватывается автоматически, если добавить в файл
   `"$schema": "./scenario.schema.json"` — это единственное поле, которое
   допустимо сверх схемы при локальной разработке, но перед коммитом его
   нужно убрать.
2. Проверьте структуру: `make seed` выводит отчёт и список нарушений.
3. Сценарий с ошибками не загружается, ранее загруженные версии не меняются.

Поля `version` в файле нет: версию присваивает загрузчик по хешу содержимого.
Правка текста создаёт новую версию, а сессии, начатые на прежней, остаются
на ней (FR32).

## Правила написания

Структуру проверяет валидатор при загрузке, содержание — ревью.

1. **Опасный вариант должен быть правдоподобным.** Ориентир: так поступил бы
   спешащий человек, а не невнимательный. Если `critical` выглядит явной
   глупостью, шаг ничему не учит.
2. **Спорный вариант — это отсрочка, а не ошибка.** `risky` продолжает диалог
   без защиты: уточнить, попросить подождать, согласиться обсудить.
3. **Безопасный вариант ведёт к безопасному паттерну**, а не просто
   «отказаться и уйти».
4. **Обратная связь строится по схеме «признак → причина → альтернатива».**
   Слова «правильно» и «неправильно» не используются: объяснение должно
   обучать, а не выносить вердикт.
5. **Ветвление сходится обратно в основную линию.** Отдельные концовки
   допустимы только на терминальных шагах.
6. **Опасный выбор не обрывает сценарий досрочно.** Пользователь должен дойти
   до разбора, а не быть наказанным выходом из тренировки.
7. **Ссылки и реквизиты — имитация** (SEC8): домены не существуют, номера карт
   и телефонов никому не принадлежат. Фронтенд не делает такие ссылки
   кликабельными.
8. **Одна схема мошенничества на сценарий.** Смешение схем размывает обучающий
   эффект и портит статистику по признакам (FR26).
